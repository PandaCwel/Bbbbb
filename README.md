# Teoria B — Prawko Mobile

Mobilna aplikacja do nauki teorii prawa jazdy.

## Stack
- React + TypeScript + Vite
- Node.js + Express API

## Konfiguracja
Skopiuj `.env.example` do `.env` i ustaw `SESSION_SECRET` oraz `SCHOOL_ID=1000470`.

## Uruchomienie
```bash
npm install
npm run dev
```

## Status
To repozytorium jest miejscem docelowym projektu. Integracja z zewnętrznym API pytań i egzaminów wymaga potwierdzenia aktualnych endpointów i formatu odpowiedzi; nie należy traktować niezweryfikowanych endpointów jako działających.
